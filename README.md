# 陪伴式对话安全边界服务

项目列出陪伴式对话中的记忆类别、能力边界和支持资源类型，帮助安全团队统一术语。当前模块不分析对话，也不实施风险干预。

基础样例保存在 `fixtures/catalog.json`，文件采用 UTF-8 编码。调整资料时应保持标识唯一，并让名称直接描述项目领域中的真实对象。

## 受控维度

各维度彼此独立，一条条目只能归属一个维度，`Load` 会拒绝不在下表中的类别：

| 维度 | 说明 |
| --- | --- |
| 使用目的 | 产品明确声明的用途；情绪陪伴不等于承诺幸福或心理健康疗效 |
| 记忆类别 | 默认只保留当前对话所需信息；记忆须可被用户查看、收缩与撤销 |
| 角色能力 | 角色能做什么、不能做什么（如不作诊断）的边界说明 |
| 年龄级别 | 成年与未成年保护等差异化级别 |
| 风险信号 | 区分普通情绪表达（不诊断化）与明确紧迫危险信号（按公开规则提示现实求助） |
| 支持资源 | 现实支持渠道、紧急求助热线等产品外资源 |
| 干预动作 | 有限、限时的干预，须说明可见依据、动作与解除时间 |
| 人工复核 | 人工仅可接触完成复核所需的最小对话片段 |
| 可解释事件 | 模型升级、消息删改、跨设备重试、误报申诉、长期高频使用；旧状态不悄然消失，也不永久附着 |
| 数据副本 | 删除主数据后须同步失效的索引与研究副本 |
